# Runtime requirements

Install the [complete package](installation.md). The native registrars only
register skill files. Skill procedures control when to call tools or execute a
script. Installation grants no authority for a skill action.

Audits need Git and read access to the target repository. To run target
verification commands, use the target toolchain and obtain the authority that
the owning skill requires. Record a command you did not run as unverified.
The skills do not require `gh`. Keep instruction and code-health references
with their owners.
